# PCE统一高级筛选布局规范

- 规则版本：`PCE-ADVANCED-FILTER-LAYOUT-V1.0`
- 生效版本：`V1.14.2.8.4.27.2.31`
- 适用范围：全部企业级列表高级筛选区域
- 事实边界：仅治理筛选呈现与响应式布局，不改变筛选字段、Provider、Runtime数据来源或业务数据

## 1. 三行语义结构

所有高级筛选区域必须由统一组件或统一布局契约输出以下顺序：

1. 查询条件：文本、枚举、远程主数据选择、布尔条件。
2. 范围条件：数值范围、日期、日期范围及其他明确的区间条件。
3. 操作按钮：查询、清空条件、重置排序等筛选相关操作；无独立操作时仍保留可诊断的操作行占位。

页面不得打乱顺序，也不得把范围条件混排到操作按钮行。

## 2. 控件尺寸

- 控件标准高度：`36px`。
- 单字段标准最小宽度：`180px`。
- 同一行网格间距：`12px`。
- 标签与控件垂直间距：`6px`。
- 区域行间距：`14px`。
- 控件统一 `width: 100%`、`min-width: 0`、`box-sizing: border-box`。
- 禁止页面为单个筛选控件声明私有高度或用内联样式覆盖标准高度。

## 3. 响应式布局

统一栅格使用以下断点：

| 可视宽度 | 每行列数 |
| --- | ---: |
| `< 768px` | 1 |
| `768px - 1023px` | 2 |
| `1024px - 1439px` | 3 |
| `>= 1440px` | 4 |

尾行左对齐，不居中，不产生页面级横向滚动。范围条件内部可使用两列子网格，但其外部占用一个标准字段列。

## 4. 运行与诊断契约

高级筛选根节点必须声明：

- `data-pce-filter-layout-version="PCE-ADVANCED-FILTER-LAYOUT-V1.0"`
- `data-pce-filter-control-height="36"`
- `data-pce-filter-control-min-width="180"`

三个区域分别声明 `data-pce-filter-row="query|range|actions"`。自动验收通过真实计算样式和元素边界验证，不得只扫描静态字符串。

## 5. 自动验收

- `FILTER-LAYOUT-HEIGHT-001`：同一筛选区域可见输入控件计算高度全部为36px。
- `FILTER-LAYOUT-WIDTH-001`：同类列宽一致，控件占满字段列且不超出容器。
- `FILTER-LAYOUT-RESPONSIVE-001`：四个断点下列数、行顺序和页面横向溢出均符合契约。

## 6. 禁止边界

本规范不得授权修改 MaterialMaster、SupplierMaster、MaterialSupplierRelation、SupplierMaterialPrice、PurchaseOrder、采购流程或 Gate；不得修改 Provider、Runtime事实来源或数据库结构；`Business Write Count = 0`。
