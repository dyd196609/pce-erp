# 供应商报价确认闭环扫描报告

- 版本：`V1.14.2.8.4.27.2.44`
- 报告标识：`Price Review Confirmation Scan Report`
- 扫描页面：`#/scm/price-review-assistant`

## 扫描结论

现有 `PurchasePriceReviewAssistant` 已具备当前报价、历史价格、供应商比较、供应关系和人工决策区域，但原人工决策只形成前端 TEST_CASE 审计，不会形成 `SupplierMaterialPrice`。本版本复用既有 `SupplierMaterialPriceRuntime`、Provider、Schema 和页面，不新增报价审批中心、价格模型、Runtime 或 Metadata 框架。

## 复用与扩展

| 能力 | 现有位置 | 处理 |
| --- | --- | --- |
| 当前报价 | `SupplierQuotation` 服务端事实 | 复用；确认时由服务端重新读取，页面不得提交供应商、物料或价格事实 |
| 历史价格 | `SupplierPriceFactRuntime` | 复用；保持只读，不转换为有效价格 |
| 当前有效价格 | `SupplierMaterialPriceRuntime` | 原位扩展人工确认会话投影 |
| 人工决策 | `PurchasePriceReviewAssistant` | 扩展为接受、拒绝、重新议价三种明确结果 |
| 页面数据接入 | 既有 Provider/Runtime | 复用；不创建第二套框架 |

## 实施边界

- 只有人工选择“接受报价”且补齐确认人、意见、税率、最小采购量、交期和有效期，才形成有效价格会话投影。
- 服务端按 `SupplierQuotation:<报价编号>:line:<行号>` 重新定位权威报价；无法绑定供应商、物料、价格或币种时拒绝生成。
- 拒绝报价、要求重新议价均不调用生成接口。
- 会话投影标记 `sourceType=SupplierQuotationConfirmed`、`factOrigin=SESSION_CONFIRMED`、`persisted=false`；服务重启后清除，不属于数据库业务写入。
- `SupplierPriceFactRuntime` 显式排除 `SESSION_CONFIRMED`，因此有效价格不会覆盖或污染历史事实和趋势分析。
- 采购订单、Gate、供应商推荐状态机均未接入该会话投影。

结论：`Price Review Confirmation Scan Report: PASS`。
