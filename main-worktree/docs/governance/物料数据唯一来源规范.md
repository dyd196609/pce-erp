# 物料数据唯一来源规范

- 规则编号：`MATERIAL-SOURCE-UNIQUE-001`
- 生效版本：`V1.14.2.8.4.27.2.22`
- 适用范围：PCE-ERP 物料主数据及采购、库存、生产等业务引用
- 状态：长期有效、持续更新

## 1. 唯一标准链

企业系统中的物料必须存在唯一主数据来源：

```text
MaterialMaster
-> PurchaseRequestItem
-> PurchaseOrderItem
-> Inventory
-> Manufacturing/MRP
```

业务模块只能引用 MaterialMaster 的身份和字段快照，不得创建或维护独立物料库。页面不得维护物料，业务选择器不得读取临时数据、Demo 数据、静态验收 rows 或模块私有 Store。

## 2. 字段契约

正式 MaterialMaster 至少提供：

- `id`、`code`、`name`
- `specification`、`unit`
- `category`、`materialType`
- `status/isActive`
- `updatedAt`

供应商关联必须来自独立、正式、可追溯的 Material-Supplier 关系；采购申请的 `suggestedSupplier` 只是业务建议，不能替代主数据关联。

## 3. 选择器来源门禁

### MATERIAL-SELECTOR-SOURCE-TRACE-001

每个物料选择器必须能输出：Page、Component、Select、Options Provider、Store（如无则明确 N/A）、API、Domain/Database、筛选条件和记录数量。

### MATERIAL-SOURCE-UNIQUE-001

同一正式环境只能有一个 MaterialMaster 事实所有者。维护页与业务引用接口读取不同数据集、不同对象或不可核对数量时，本门禁为 FAIL。

### MATERIAL-MASTER-FIELD-COMPLETE-001

采购可选物料的编码、名称、规格、单位、分类、类型、状态和维护时间必须完整。字段缺失时显式阻断或提示维护，不得由页面默认值补齐。

### MATERIAL-CODE-MATCH-001

MaterialMaster与供应商价格/关系事实必须通过服务端主键或完整物料编码严格匹配。只允许去除首尾空白和统一大小写；`MAT-000001`、`MT001` 等不同业务编码不得按序号、名称或页面内部ID强行等同。编码冲突时必须阻断事实继承。

## 4. 迁移边界

发现多来源时先冻结数据并输出来源矩阵、字段映射、重复风险与迁移计划。未经独立迁移版本授权，禁止删除、合并、回写或自动创建 MaterialMaster；诊断版本必须保持 `Business Write Count = 0`。
