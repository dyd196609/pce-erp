# 供应商价格事实智能分析与历史价格能力建设报告

- 版本：`V1.14.2.8.4.27.2.37`
- 页面：`#/foundation/erp/supplier-price-analysis`
- 事实所有者：`SupplierPriceFactRuntime`
- 分析模式：`READ_ONLY_REFERENCE`

## 智能化影响评估

本版本在既有价格事实层上增加只读分析能力，可为人工核价、成本分析和供应商评估提供证据，但不得自动选择供应商、自动核价、生成采购价格或创建采购订单。

## 已有能力扫描与复用方案

完整扫描结果见《供应商价格事实智能分析能力清单》。实施复用同一个服务端 Runtime/API、前端 Provider/Runtime、Metadata Registry、Filter Runtime、Dropdown Runtime、`PceEnterpriseListTable`、`PceEnterpriseAdvancedFilter`、`PceBusinessStatus` 与 `PceListPageShell`。

## 实施边界

- 允许：只读最低采购价、最近采购价、平均采购价、环比与总体变化率、趋势、供应商价格比较和异常提醒。
- 禁止：价格维护、自动核价、自动推荐、自动下单、页面计算价格、Gate 传递价格。
- 主数据绑定：SupplierMaster、MaterialMaster、MaterialSupplierRelation 和 SupplierPriceFact 仍是名称与关系事实所有者，分析页面不得维护这些对象。
- 数据库结构与业务数据均不修改，Business Write Count 为 `0`。

## 历史价格模型

历史分析按 `Supplier + Material + Currency + Unit` 分组，按有效日期及来源引用稳定排序。输出最低价、最近价、平均价、上次价格、环比变化、总体变化、趋势、样本数和首末日期。全部指标由服务端计算，页面仅格式化展示。

## 供应商价格比较

比较以 `Material + Currency + Unit` 为口径，每个供应商取最近价格事实，输出候选数量、均价、最低参考价与偏离率。`isLowestReference` 仅为事实标识，`decision` 固定为 `null`，不得解释为推荐或采购决定。

## 异常规则规划与实现

| 规则 | 条件 | 边界 |
| --- | --- | --- |
| 异常上涨 | 最近环比 `>= 20%`，至少 2 个样本 | 仅提醒 |
| 异常下降 | 最近环比 `<= -20%`，至少 2 个样本 | 仅提醒 |
| 异常低价 | 偏离同口径均价 `<= -30%`，至少 3 个供应商 | 仅提醒 |
| 异常高价 | 偏离同口径均价 `>= 30%`，至少 3 个供应商 | 仅提醒 |
| 长期无更新 | 相对数据集最近历史日期超过 180 天 | 仅提醒 |

规则版本为 `PRICE-INTELLIGENCE-RULES-V1.0`。长期无更新使用服务端数据集最大历史日期作为确定性参考，避免同一事实因浏览日期不同而产生不可复现结果。

## 自动验收规则

- `PRICE-INTELLIGENCE-SOURCE-001`：页面、诊断与验收仅消费 `SupplierPriceFactRuntime` 服务端事实。
- `PRICE-HISTORY-ANALYSIS-001`：历史明细及最低、最近、平均、变化和趋势输出完整。
