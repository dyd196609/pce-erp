# 供应商核价智能辅助与人工决策闭环设计报告

- 版本：`V1.14.2.8.4.27.2.38`
- 页面：`#/scm/price-review-assistant`
- 页面标题：供应商核价智能辅助
- 事实所有者：`SupplierPriceFactRuntime`
- 规则所有者：`PriceReviewRuleRuntime`

## 智能化影响评估

本版本把 V2.37 的价格事实分析组织成人工核价上下文，提供证据汇集与规则提示。系统不作出核价结论，不选择供应商，不修改报价，不创建采购订单。

## PurchasePriceReviewContext

上下文包括：

1. 当前报价事实：供应商、物料、报价、币种、来源和日期，来源为 `SupplierQuotationItem`。
2. 历史价格参考：最低、最近、平均、次数、最近日期与趋势，来源为 `SupplierPriceFactRuntime.intelligenceAnalysis`。
3. 供应商比较：同物料、同币种、同单位的最近价、均价、偏离和候选数量。
4. 供应商关系表现：交期、质量等级与准时率，来源为 `MaterialSupplierRelationRuntime`；缺失保持待评估。
5. 规则提示：只生成提示，不生成决定。
6. `PurchasePriceDecisionContext`：待人工确认的空白输入契约。

当前运行事实形成 1 个核价案例：`PPRC-SPF-SQ-1-1`，当前报价来自 `SupplierQuotation:SQ-202608050001:line:1`。同币种历史与可比供应商不足时保持样本不足，并生成数据质量提示，不跨币种兜底。

## PriceReviewRuleRuntime

| 规则 | 条件 | 输出 |
| --- | --- | --- |
| `QUOTE_ABOVE_LATEST_20` | 当前报价高于最近采购价20% | 价格上涨风险提示 |
| `QUOTE_BELOW_LOWEST_30` | 当前报价低于历史最低价30% | 异常低价提示 |
| `QUOTE_PEER_AVERAGE_DEVIATION_20` | 偏离同口径供应商均价20% | 价格偏离提示 |
| `HISTORY_REFERENCE_INSUFFICIENT` | 同币种同单位历史样本不足 | 历史数据完整性提示 |
| `SUPPLIER_COMPARISON_INSUFFICIENT` | 可比供应商不足2家 | 比较完整性提示 |

规则版本：`PRICE-REVIEW-ASSIST-RULES-V1.0`。所有输出的 `decision` 为 `null`，`requiresHumanConfirmation=true`。

## 人工决策闭环

```text
SupplierQuotation
-> SupplierPriceFactRuntime
-> 历史价格与供应商比较
-> PriceReviewRuleRuntime 提示
-> 人工填写核价意见、确认人、确认结果
-> TEST_CASE_SESSION_AUDIT
```

在数据库结构与业务写入均被禁止的前提下，页面确认只能形成当前浏览器会话内的验收记录：

- `auditMode=memory_session_only`
- `persisted=false`
- `isBusinessDecision=false`
- `businessStateAdvanced=false`
- `businessProgressWriteCount=0`

刷新后会话记录清空，不冒充正式 PriceApproval。未来需要永久保留人工核价结果时，必须另立授权版本，复用正式 PriceApproval Action、权限、状态机和审计持久化。

## 禁止自动行为

- 自动选择最低价：关闭。
- 自动推荐供应商：关闭。
- 自动修改报价：关闭。
- 自动确定采购价格：关闭。
- 自动创建采购订单：关闭。
- Gate 覆盖价格：不存在。
