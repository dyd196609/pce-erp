# 采购业务主数据引用治理规范

版本：V1.14.2.8.4.27.2.45.11

## MASTER-DATA-REFERENCE-CLOSURE-001

采购请求、询价、供应商报价、比价、核价、供应商推荐、有效价格、采购订单及其只读分析模型中的供应商身份，进入正式业务动作前必须唯一解析到 SupplierMaster。解析只允许正式主键、正式编码或经审计的 `SupplierBusinessReferenceMapping`；禁止名称模糊匹配、字符串变换和前端猜测映射。

## MASTER-DATA-REVERSE-ENRICHMENT-001

业务事实中存在、SupplierMaster 中缺失的供应商，可按“只读扫描 → 多源证据归并 → 冲突检查 → 显式授权写入 → 完整性复核”反向补全。供应商名称、旧业务编码、报价编号属于业务事实字段；正式编码、分类、联系人、电话、地址、送货地址、信用等级与交期属于开发环境补全字段，必须记录来源、执行版本和回滚说明。

## SUPPLIER-RECOMMENDATION-MASTER-REFERENCE-001

正式供应商推荐上下文中的全部候选及人工选中供应商必须携带 `supplierMasterId`、`supplierMasterCode`、`supplierMasterName` 和原始 `sourceReference`。任一正式候选无法解析时，推荐入口必须阻断；推荐不得自动选择供应商、生成价格或创建采购订单。

## 职责边界

- SupplierQuotation 保存报价事实，不承担供应商主数据维护。
- PriceApprovalPreparation / PriceApprovalResult 保存人工核价决策及来源链。
- SupplierMaterialPrice 只由确认报价动作归档，不接受主数据补全程序直接写入。
- SupplierPriceFact 保持只读，不因主数据补全或有效价格归档被改写。
- MaterialSupplierRelation 仅表达供应关系与交货周期，不进入价格事实生成。

## 回滚

确认新增 SupplierMaster 尚无下游正式引用时，先删除显式业务引用映射，再删除对应开发补全主数据；已形成 PriceApprovalResult 或 SupplierMaterialPrice 时禁止直接删除，必须保留事实链并通过独立治理变更处理。
