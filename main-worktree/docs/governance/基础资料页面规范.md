# 基础资料页面规范

- 规则编号：`MASTER-DATA-PAGE-001`
- 生效版本：`V1.14.2.8.4.27.2.35`
- 上位规范：`PCE-ERP智能化开发总纲.md`、`元数据驱动列表规范.md`、`PCE-ERP页面与交互开发规范.md`
- 适用范围：企业基础资料中心的主数据、关系、价格和事实查看页面

## 1. 页面分类

基础资料入口必须在既有 Metadata 中声明唯一 `pageKind`：

| 分类 | 用途 | 列表动作 | 写入边界 |
|---|---|---|---|
| `fact` | 查看不可变或派生业务事实 | 查看 | 页面零写入 |
| `master` | 查看和维护企业主数据 | 查看、编辑 | 仅显式人工维护版本可写 |
| `config` | 查看和维护受治理配置 | 查看、编辑、停用/启用 | 必须有权限、Guard和审计 |

`SupplierPriceFact` 固定为 `fact`。物料与供应商正式档案固定为 `master`。派生的物料供应商关系 Runtime 不得因页面存在编辑组件而变成可写主数据。

## 2. 页面运行链

页面必须复用：

```text
Schema/Registry
  -> Filter Runtime + Dropdown Runtime
  -> PceEnterpriseListTable
  -> PceEnterpriseAdvancedFilter
  -> PceBusinessStatus
```

字段、选项、状态、数量和动作均不得在页面形成第二来源。页面级统计显示当前筛选结果时，必须读取企业列表的同一结果集合。

## 3. 价格事实日期说明

SupplierPriceFact页面必须明确区分：

- 单日日期：历史采购订单已经执行形成的价格事实，生效日与失效日相同；
- 日期区间：报价或基础价格的有效期间，由生效日期和失效日期组成；
- 缺失有效期：显示“待补有效期”，页面不得自动补造。

说明只解释服务端事实，不得在页面推导或修改日期。

## 4. 本版本实施边界

V1.14.2.8.4.27.2.35只治理列表运行能力与展示边界，不修改MaterialMaster、SupplierMaster、SupplierPriceFact、PurchaseOrder、Gate或任何业务数据，Business Write Count固定为0。

## 5. MASTER-DATA-VISIBILITY-001 主数据可见性门禁

任何报告宣称 Master Data（主数据）已新增，必须以同一主键和业务编码证明 Database（数据库）、正式 API（服务接口）、Runtime（运行层）和正式 Browser（浏览器）页面四层均存在且可搜索。四层任一缺失时不得输出 `ADDED` 或 `MAPPED PASS`，也不得新增重复对象掩盖读取链、租户、状态、过滤、分页或页面投影问题。

SupplierMaster（供应商主数据）的正式页面必须显示正式编码、名称、分类、联系人、联系方式、供应商地址、送货地址和用户可见状态；供应商地址与送货地址保持独立字段。
