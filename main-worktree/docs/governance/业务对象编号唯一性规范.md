# 业务对象编号唯一性规范

- 规则编号：`BUSINESS-OBJECT-NUMBER-UNIQUE-001`
- 生效版本：`V1.14.2.8.4.27.2.15`
- 适用范围：全部PCE-ERP业务对象及其列表、详情、打印、导出、搜索和报表
- 状态：长期有效

## 1. Canonical Number Field

每个业务对象必须在Domain层声明唯一Canonical Number Field和唯一读取函数。采购订单固定为：

```text
Business Object: PurchaseOrder
Canonical Number Field: objectNo
Canonical Reader: getPurchaseOrderNumber(order)
```

## 2. 强制消费规则

列表、详情、打印、导出、搜索、排序和报表必须调用同一Canonical Reader。Provider和Runtime不得用兼容别名、来源编号或页面参数替代Canonical字段。

来源Gate、申请、询价、报价、核价编号只能作为`SourceRelations`独立展示，禁止拼接或回填到业务编号。

## 3. 失败门禁

Canonical字段缺失、读取器数量不等于1、消费端直接读取第二编号源或编号命中对象专项禁止片段时必须FAIL。历史别名只能用于迁移识别，不得成为用户可见编号来源。

## 4. 变更记录

- `V1.14.2.8.4.27.2.15`：建立全局业务对象编号唯一性规则并冻结`PurchaseOrder.objectNo`。
