# 高级筛选布局公共组件影响清单

- 版本：`V1.14.2.8.4.27.2.31`
- 公共组件：`PceEnterpriseAdvancedFilter`、`PceAdvancedFilterField`
- 变更契约：三行语义布局、36px控件高度、180px最小字段宽度、统一12px间距和四级响应式栅格
- 影响类型：结构、视觉、响应式；不影响数据、筛选算法、Provider、Action或业务写入

## 直接消费者

`PceEnterpriseListTable` 是统一高级筛选组件的直接消费者。仓库内直接使用该列表基座的页面与组件包括：

- EMD/PDE：EnterpriseMasterDataPage、PdeFoundationPage。
- SCM：ScmInquiryPreparationPage、ScmPriceApprovalRuntimePage、ScmPurchaseInquiryNodePage、ScmPurchaseInquiryWorkbenchPage、ScmPurchaseOrderCreateEntryPage、ScmPurchaseOrderGatePage、ScmPurchaseRequestPage、ScmQuoteComparisonWorkbenchPage、ScmSupplierRecommendationPage、ScmSupplierQuoteEnterpriseList、ScmPriceApprovalPreparationEnterpriseList。
- 供应商治理：SupplierPayableV83Page、SupplierPerformanceBasePage、SupplierReconciliationV82Page、SupplierSettlementV84Page。
- 银行发送治理：BankConnectorAdapterReviewPage、BankSendExecutionFrameworkReviewPage、BankSendDualIsolationCheckPage、BankSendChainTracePage、BankSendSimulationAuditPage、BankSendPreparationPage、BankSendFinalApprovalPage、BankSendIsolationGatePage、BankSendRequestPage、BankSendProductionReleaseReviewPage、BankSendTaskPage、BankSendSimulationPage。
- 验收组件：PceEnterpriseListCanaryView。

## 本版本重点页面

四个重点入口均由 `ManufacturingFoundationPage` 承载，使用同一布局契约：

- `/foundation/erp/material-suppliers`
- `/master-data/suppliers`

## 冻结与恢复

保留原字段Schema、筛选状态、排序、表格、分页、操作和数据加载逻辑。若回归失败，仅回退布局组件、布局Runtime与CSS，不回退或重写业务数据。
