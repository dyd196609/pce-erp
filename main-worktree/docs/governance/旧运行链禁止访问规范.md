# 旧运行链禁止访问规范

- 生效版本：`V1.14.2.8.4.27.2.16`
- 适用范围：PCE-ERP 全部业务对象运行链、页面、打印、导出、导入与流程中心
- 状态：长期有效、持续更新

## 1. RUNTIME-CHAIN-001 业务对象唯一运行链

每个业务对象只允许一条活动读取链：

```text
Domain -> RuntimeAdapter -> RuntimeModel/ViewModel -> Page
```

页面、打印、导出和报表禁止直接读取 `sourceObject`、`sourceObjects`、`sourceGate`、`sourceChain`、`temporaryModel` 或 Provider 原始结构。升级后的旧 Adapter、Formatter、Excel 生成器必须删除业务逻辑；确需保留历史导入名时，只允许无业务逻辑的转发入口。

采购订单活动链固定为：

```text
Router -> PurchaseOrderRuntimeAdapter -> PurchaseOrderRuntimeModel -> List/Detail/Print/Export
```

活动 Runtime 入口数不等于 1、页面二次聚合 RuntimeModel、或旧 Adapter 仍被活动页面导入时，本规则为 FAIL。

## 2. LEGACY-FIELD-BLOCK-001 / NUMBER-LEGACY-BLOCK-001

`PurchaseOrder.objectNo` 是采购订单唯一 Canonical Number，统一读取器为 `getPurchaseOrderNumber()`。`purchaseOrderNo`、`poNo`、`sourceGateNo`、`gateNo` 只允许在迁移边界识别，不得进入采购订单 RuntimeModel、ViewModel、列表、详情、打印、导出或页面 DOM。

采购订单编号显示值不得包含 `PAP-PI`、`QC-`、`Gate`、`source` 等来源链片段。来源关系不得拼接、回填或替代采购订单编号。

## 3. IMPORT-RELATION-002 Header/Detail 真实关联

采购订单导入工作簿只允许两个业务 Sheet：`采购订单基本信息` 与 `采购订单物料明细`。两个 Sheet 第一行为字段名称、第一列为序号，且都包含来自 Schema/Contract 的 `采购订单编号`。

```text
Header.采购订单编号 = Detail.采购订单编号
```

Detail 的关联键为空或不能命中 Header 时必须 FAIL；不得按行号、首条 Header、页面缓存或隐式顺序关联。旧 CSV/XLSX 生成逻辑不得继续维护第二套字段和关系规则。

## 4. PROCESS-CENTER-ENTRY-002 流程中心唯一入口

模块快捷入口、业务导航、页面按钮与直接 URL 必须归一到：

```text
/process-center -> ProcessCenterRuntime -> ProcessCenterRuntimeModel -> EnterpriseOSPage
```

允许 `module` 查询参数选择同一 RuntimeModel 内的模块，不允许模块私有流程中心、第二 Route Component 或第二 Runtime。正式入口数与正式 Runtime 数必须同时等于 1。

## 5. 验收与边界

验收至少输出：活动 Runtime 数、旧 Adapter 活动导入数、旧字段页面命中数、Header/Detail 关联结果、流程中心 Route/Runtime 数和 `Business Write Count`。

本规范不授权修改 PurchaseOrderGate 业务规则、SupplierRecommendation、审批、生命周期、收货、入库、付款、数据库结构或生产业务数据。所有扫描、投影、模板生成和验收均须保持 `Business Write Count = 0`。
