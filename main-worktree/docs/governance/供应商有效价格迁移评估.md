# Price Migration Assessment

- 版本：`V1.14.2.8.4.27.2.43`
- 结论：`ISOLATED`
- 正式转换：0条

## 早期测试数据

`manufacturing-foundation-state-v1`中的3条浏览器测试价格继续隔离。它们缺少可复核的审批对象、来源类型与来源编号，禁止进入正式价格。

## 审批候选

服务端共有12条历史审批候选。全部缺少最低采购量、税率、交货周期、生效日期和失效日期；其中4条供应商编码不能严格绑定SupplierMaster。采购需求数量不得替代最低采购量，报价接收时间不得自动扩展为有效期，税率与交期不得设置默认值。

因此12条候选全部保持`ISOLATED_INCOMPLETE`。当既有审批对象未来同时具有供应商、物料、正价、币种、税率、最低采购量、交期、有效期、报价来源编号和Approved状态时，既有Runtime才可将其投影为正式`SupplierMaterialPriceRuntimeModel`。

## 自动生成边界

- 禁止历史采购价转正式价；
- 禁止`SupplierPriceFact`转正式价；
- 禁止最低价自动转正式价；
- 禁止页面或Gate补值；
- `autoGenerationEnabled = false`；
- Business Write Count = 0。
