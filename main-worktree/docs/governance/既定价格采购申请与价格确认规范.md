# 既定价格采购申请与价格确认规范

1. AGREED_PRICE 必须从正式 PurchaseRequest 开始，明细来源为 MaterialMaster。
2. 申请创建阶段不得要求或绑定 SupplierMaterialPrice，不得保存执行价格快照。
3. 审批后不得进入询价准备、采购询价、供应商报价、报价比较、采购核价或供应商推荐。
4. 审批后的最小闭环状态为 `AGREED_PRICE_PURCHASE_REQUEST_READY_FOR_PRICE_CONFIRMATION`。
5. 后续价格确认只能读取有效 CURRENT SupplierMaterialPrice，并继续受供应商、物料、供应关系、币种、税率、生效和失效日期治理。
6. SupplierMaterialPrice 的管理列表继续属于正式价格管理能力，禁止用该列表冒充采购申请创建页。
