# SupplierSystem Intelligence Assessment

- 版本：`V1.14.2.8.4.27.2.32`
- 范围：供应商基础资料至PurchaseOrder的现有采购闭环
- 评估原则：直接复用优先；重大业务重构暂缓；无明确收益保持现状；不授权业务写入

## 1. 逐项评估

| 对象 | 已有能力/事实所有者 | 可安全智能化升级 | 人工与交易边界 | 建议 |
|---|---|---|---|---|
| 供应商档案 | `SupplierMasterRuntime`、`masterDataRegistry`、企业列表/筛选Runtime | Schema驱动列表、完整性/重复风险提示、受治理下拉 | 同名合并、分类和基础资料变更必须人工Action | 直接复用 |
| 供应商关系 | `MaterialSupplierRelationRuntime`、关系使用矩阵 | 覆盖率、缺口、来源和异常关系提示 | 新建关系、主供应商和交期确认必须人工 | 直接复用 |
| 供应商价格 | `SupplierMaterialPriceRuntime`、报价价格事实 | 历史价格比较、缺失/异常提示、来源展示 | 价格确认、启停与生效必须人工授权 | 直接复用 |
| 采购申请 | `purchaseRequestProviderRuntimeRegistry.js`及既有Schema/Action | 字段生成、完整性检查、候选供应商证据 | 申请提交、数量和需求日期保持人工 | 直接复用 |
| 询价 | PurchaseInquiry领域Runtime、`purchase_inquiry_service.py` | 询价准备度、候选集合和字段映射校验 | 创建、激活和发送询价必须人工显式动作 | 直接复用 |
| 报价 | SupplierQuotation Runtime、`supplier_quotation_service.py` | 报价规范化、完整性、异常与可比性提示 | 报价确认不得被系统伪造或改写 | 直接复用 |
| 核价 | PriceApproval现有Domain/Guard/Runtime | 比价证据、风险与核价准备度 | 核价结论、意见和审批必须人工 | 直接复用 |
| 供应商推荐 | Recommendation Evidence/Decision/Guard | 展示候选证据、规则解释、完整性与风险提示 | 禁止自动选最低价、自动推荐落地或越过人工确认 | 直接复用，决策写入保持现状 |
| PurchaseOrder | PurchaseOrder Gate/Guard/Domain、`purchase_order_supplier_fact_runtime.py` | 只读来源追踪、草稿校验、供应商信息与风险提示 | 创建、数量、价格、交期、提交、审批和状态推进均须人工/既有Guard | 只读能力直接复用；业务重构暂缓 |

## 2. Upgrade Recommendation

### 2.1 本版本执行

- 用《PCE-ERP智能化开发总纲》接管所有未来版本的启动流程。
- 将现有Schema、Registry、Runtime、企业列表、筛选、下拉、权限和验收能力登记为优先复用所有者。
- 将供应商采购链的智能化定位为“服务端事实上的只读证据、建议、解释和校验”，保留既有人工决策和Guard。

### 2.2 独立版本再评估

- 企业用户列名、隐藏、排序、筛选和下拉来源的持久化配置，需要租户/角色权限、版本、审计、回滚及服务端事实，属于重大扩展，暂缓。
- 历史Platform Meta Runtime与`frontend/src/meta`的收敛，需要消费者和兼容性审计，暂缓。
- 任何自动供应商选择、自动核价、自动审批、自动创建或推进PurchaseOrder均不安全，不纳入升级。

### 2.3 保持现状

已闭环的采购业务对象身份、来源关系、状态机、Gate、人工数据优先级和交易写入入口保持不变。本版本`Database Changed=NO`，`Business Write Count=0`。
