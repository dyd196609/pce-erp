# PurchaseOrder Schema Gap Report（采购订单结构差距报告）

版本：V1.14.2.8.4.27.2.46-Batch2

迁移前，正式 `procurement.PurchaseOrder` 缺少采购模式、来源轨迹、价格追溯状态和供应商快照；
`PurchaseOrderItem` 缺少采购申请明细、核价结果、有效价格外键及价格/物料快照。

最小迁移 `procurement.0020_standard_purchase_price_link_v46_batch2` 已补齐上述字段。历史订单使用
`LEGACY`（历史兼容）与 `LEGACY_UNTRACED`（历史未追溯）默认值；迁移不运行数据回填，不伪造 475 条
历史价格关系。`makemigrations --check --dry-run` 返回 `No changes detected`（无迁移漂移）。

当前真实验收链的两个既有历史结构事实保持不伪造：`SupplierQuotation`（供应商报价）没有独立行表，
报价行以 `SupplierQuotation:SQ-202608040011:line:1` 标识；该早期核价结果的
`PriceApprovalPreparation`（核价准备）外键为空，但保留 `preparationIdentity=SESSION-PAP-4-1`。
本批没有越权重写既有核价历史。
