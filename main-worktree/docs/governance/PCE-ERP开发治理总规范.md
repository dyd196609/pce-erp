本文件不建立第二套总纲。所有任务必须继续遵循现行总纲规定的读取顺序与强制执行链：

```text
治理加载 -> 智能化影响评估 -> 已有能力扫描 -> 复用方案 -> 实施边界
-> 历史案例 -> 边界冻结 -> 现状扫描

```

全部开发任务还必须读取`docs/governance/PCE-ERP智能化开发总纲.md`；包含页面或可运行入口的任务必须读取`docs/governance/真实运行验收规范.md`。这些文件是现行唯一总纲下的强制专项规范，不建立第二个最高入口。必须保持服务端事实唯一、已有智能能力优先、最小修改、数据连续性、失败显式与已验收资产保护。`Automatic Acceptance`、`Browser Human Acceptance`、`Build`任一不为PASS，或存在任何适用的FAIL/UNKNOWN时，不得签发READY。
