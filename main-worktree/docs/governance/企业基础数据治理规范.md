# 企业基础数据治理规范

- 规则编号：`MASTER-DATA-SOURCE-001`
- 生效版本：`V1.14.2.8.4.27.2.22`
- 适用范围：PCE-ERP 企业基础数据页面、Provider、业务引用接口及验收事实
- 状态：长期有效、持续更新

## 1. 唯一事实原则

企业基础数据页面、业务选择器、API、Provider、诊断与验收必须读取同一服务端事实集合。页面可使用只读投影，但投影的对象身份、记录数量和维护位置必须能追溯到唯一 Domain/数据库来源。

```text
MasterData Domain/Database
-> MasterData Provider/API
-> Business Reference API
-> Business Selector/ViewModel
-> Page
```

禁止把静态验收 rows、Demo 数据、页面 state 或模块私有数据集注册为与正式主数据同名的第二事实源。验收数据需要保留时，必须标记为 acceptance/demo，并与正式业务路由、Provider 和数量诊断隔离。

## 2. 业务引用规则

1. 业务模块只保存主数据身份及业务时点快照，不得维护独立主数据目录。
2. 选择器必须通过受治理 Provider/API 查询主数据；不得从页面常量或本地 Store 补齐。
3. 同一主数据对象的维护页与业务选择器必须报告相同的权威来源、筛选条件及记录数量。
4. 规格、单位、分类、类型、状态、维护时间等字段必须由主数据服务端事实提供。
5. 供应商关联若不是 MaterialMaster 的正式关系，必须明确标记为“未建立主数据关联”，不得由采购申请建议供应商字段冒充。

## 3. 验收门禁

- `MASTER-DATA-SOURCE-001`：维护页与业务引用接口拥有同一事实所有者。
- `MASTER-DATA-COUNT-CONSISTENCY-001`：相同筛选条件下记录数量一致。
- `MASTER-DATA-DEMO-ISOLATION-001`：静态/Demo/Acceptance 数据不进入正式业务选择器。

任一门禁失败时只能输出诊断或整改方案，不得以迁移、删除或前端合并数据使验收通过。
