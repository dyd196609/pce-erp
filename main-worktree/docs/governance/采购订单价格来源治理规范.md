# 采购订单价格来源治理规范

版本：V1.14.2.8.4.27.2.46-Batch2

## PURCHASE-ORDER-PRICE-SOURCE-001

`STANDARD`（标准采购）新订单的唯一执行价格来源是服务端持久化的 `SupplierMaterialPrice`
（供应商物料有效价格）。Gate、页面、原始报价、历史价格事实、物料默认价及前端计算均不得成为执行价。

## PURCHASE-ORDER-PRICE-SNAPSHOT-001

订单创建时保存单价、税率、币种、供应商、物料、规格与单位快照。详情和打印读取订单快照；后续价格或
主数据变化不得覆盖历史订单。

## PURCHASE-ORDER-SUPPLIER-MATERIAL-PRICE-LINK-001

`PurchaseOrderItem`（采购订单明细）必须同时保存 `SupplierMaterialPrice` 和其
`PriceApprovalResult`（核价结果）正式外键。只保存编号文本或只保存快照均不合规。

## PURCHASE-ORDER-MASTER-DATA-REFERENCE-001

订单头必须引用正式 `SupplierMaster`（供应商主数据）；订单行必须引用正式 `MaterialMaster`
（物料主数据）和 `PurchaseRequestItem`（采购申请明细）。字符串只承担快照显示，不承担唯一身份。

## PURCHASE-ORDER-HISTORY-PROTECTION-001

历史订单不得批量伪造价格关系。无法可靠追溯的记录保持 `LEGACY_UNTRACED`（历史未追溯）；新标准订单
必须为 `CURRENT_LINKED`（当前已链接）。现有订单编号规则保持不变。

## 事务与幂等

价格、主数据、申请明细、订单头和订单行在同一事务复核并写入；任一失败整单回滚。同一
`creationRequestId`（创建请求编号）复用现有订单，不重复生成。
