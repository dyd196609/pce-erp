# 采购三模式入口与流程路由规范

版本：`V1.14.2.8.4.27.2.46-Batch2.2-R2`

## 统一入口

采购申请首页直接提供三个互斥业务入口；通用采购申请表单不得再次要求用户选择采购方式。采购订单页面不得提供第二套三模式卡片。

| purchaseMode | 统一路由代码 | 本版本行为 |
|---|---|---|
| `STANDARD` | 新增采购申请 / `STANDARD_PURCHASE_FLOW` | 从 MaterialMaster 选择物料；采购申请 → 询价 → 报价 → 比价 → 核价 → SupplierMaterialPrice → Gate → PurchaseOrder |
| `AGREED_PRICE` | 既定价格采购 / `AGREED_PRICE_ADMISSION` | 仅从 CURRENT SupplierMaterialPrice 进入；R2 提供入口、数据源与路由基础，完整业务由 Batch3 承接 |
| `DIRECT` | 直接采购 / `DIRECT_PURCHASE_WORKBENCH` | 正式授权通过后进入 `#/scm/purchase-order/create`，直接选择供应商的 CURRENT SupplierMaterialPrice |

服务端 `ProcurementModeRouter` 是唯一模式路由决策者，不建立平行流程引擎。DIRECT 必须同时满足服务端权限决策、前端显示控制、路由准入和创建 API 再校验；授权事实来自 User、Role、Permission、Organization 与 Runtime，禁止按用户名或前端角色字符串硬编码。

STANDARD、AGREED_PRICE 和 DIRECT 均不在采购订单页二次选择。AGREED_PRICE 与 DIRECT 不得先自由选择 MaterialMaster 再反查价格；其物料、供应商、价格和价格版本必须由正式 SupplierMaterialPrice 一次确定。历史 `MANUAL_STANDARD_PURCHASE_ORDER_CREATION` 对象保持原样，但其新建入口永久退役。
# Batch2.2-R3 补充

- STANDARD：`/scm/purchase-request` 打开正式 PurchaseRequest 表单，物料来自 MaterialMaster，审批后可进入询价准备。
- AGREED_PRICE：`/scm/purchase-request/agreed-price` 打开“新建既定价格采购申请”，复用同一 PurchaseRequest 表单，审批后停在既定价格确认就绪，禁止进入询价。
- DIRECT：`/scm/purchase-order/create` 进入直接采购工作台，正式价格对象来自 SupplierMaterialPrice CURRENT，必须完成 Gate 和真实人工确认后才可创建订单。
