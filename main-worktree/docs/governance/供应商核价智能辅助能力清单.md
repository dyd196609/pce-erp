## 复用与边界结论

- `PurchasePriceReviewContext` 由同一 SupplierPriceFact API 输出，页面不拼接价格或主数据名称。
- 规则只输出 `ASSISTIVE_PROMPT_ONLY`，每条提示具有规则编码、版本、阈值和人工确认标记。
- 人工确认复用既有核价上下文所有权，记录为 `TEST_CASE_SESSION_AUDIT / memory_session_only`；不调用正式核价转换接口。
- 自动最低价选择、自动供应商推荐、自动修改报价和自动创建订单全部关闭。
