# 页面汇总统计数据来源规范

- 规则编号：`MASTER-DATA-STATISTICS-SOURCE-001`
- 生效版本：`V1.14.2.8.4.27.2.29`
- 适用范围：企业基础资料首页及后续页面汇总统计
- 状态：长期有效、持续更新

## 1. Runtime 唯一来源

所有页面统计必须由服务端 Runtime 输出。页面只能显示 Runtime 的同名字段，不得从页面列表、缓存、Fixture、Demo Store、上一页状态或静态数字重新计数。

企业基础资料首页固定来源链为：

```text
MaterialMaster Runtime ----------------------> materialCount
SupplierMaster Runtime ----------------------> supplierCount
MaterialSupplierRelation Runtime ------------> supplierMaterialRelationCount
SupplierMaterialPrice Runtime ---------------> supplierPriceCount
                         |
                         v
MasterDataStatisticsRuntime -> Provider -> Foundation Page DOM
```

`MasterDataStatisticsRuntime` 是四项汇总字段的唯一聚合入口。聚合只允许执行只读计数，不得创建、补齐、修改或删除主数据和采购业务对象。

## 2. 字段契约

| Runtime 字段 | 权威来源 | 页面含义 |
|---|---|---|
| `materialCount` | `MaterialMasterRuntimeAdapter` | 可采购且启用的正式物料数量 |
| `supplierCount` | `SupplierMasterRuntimeAdapter` | SupplierMaster 正式供应商数量 |
| `supplierMaterialRelationCount` | `MaterialSupplierRelationRuntime` | 已持久化并能严格映射主数据的供应商物料关系数量 |
| `supplierPriceCount` | `SupplierMaterialPriceRuntime` | 上述关系中有效正价事实数量 |

关系和价格 Runtime 在数据库结构冻结期间，只能从持久化 `SupplierQuotation.items` 投影；页面私有 `manufacturingFoundationStore` 不得成为正式统计来源。

## 3. 禁止事项

- 禁止在页面写死统计数字。
- 禁止以 Fixture、Demo、Acceptance 或 localStorage 集合的长度代替 Runtime 数量。
- 禁止读取 `enterprise_master_data` 静态 rows 计算 SupplierMaster 数量。
- 禁止读取失败时回退到旧页面 Store 或默认 0；必须显示加载失败诊断。
- 禁止为了通过统计验收修改 MaterialMaster、SupplierMaster、数据库结构或采购业务数据。

## 4. 自动验收

- `MASTER-DATA-STATISTICS-SOURCE-001`：四个字段分别报告唯一 Runtime 来源，页面只调用 `MasterDataStatisticsRuntime`。
- `MASTER-DATA-COUNT-CONSISTENCY-001`：页面 DOM 数量必须等于同次 Runtime 响应数量。
- 数据库文件哈希、业务对象数量及业务状态在验收前后保持不变。
- `Business Write Count = 0`。
