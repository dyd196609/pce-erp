# 流程中心入口统一规范

- 规则编号：`PROCESS-CENTER-ENTRY-UNIQUE-001`
- 生效版本：`V1.14.2.8.4.27.2.15`
- 适用范围：所有进入`#/process-center`的菜单、模块、工作台、流程与直接URL入口
- 状态：长期有效

## 1. 唯一运行链

流程中心固定运行链为：

```text
Router -> ProcessCenterRuntime -> ProcessCenterRuntimeModel -> EnterpriseOSPage
```

`ProcessCenterRuntime`是唯一正式运行入口，业务流程Registry仅作为它的事实源。页面不得直接分别读取不同Registry构造另一套流程中心模型。

## 2. 入口一致性

模块入口、企业操作系统入口、返回流程中心按钮和直接URL必须导航到`/process-center`，可使用`module`查询参数选择同一Runtime Model中的模块，但不得切换Runtime或页面组件。

Router、Runtime、Data Model与Page必须一一对应。流程中心Runtime正式入口数量必须等于1。

## 3. 验收

验收必须检查Router组件、Runtime代码、Runtime Model标识、Registry来源、入口归一化结果和两种以上入口的DOM结构。任一入口渲染不同Page或不同Runtime时FAIL。

## 4. 变更记录

- `V1.14.2.8.4.27.2.15`：建立流程中心唯一Runtime与入口归一化门禁。
