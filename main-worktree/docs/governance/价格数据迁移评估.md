# Price Data Migration Assessment

- 版本：`V1.14.2.8.4.27.2.42`
- 结论：`ISOLATED`，本版本不迁移、不伪造价格。

## 早期3条浏览器测试数据

`manufacturing-foundation-state-v1`中的3条数据使用浏览器本地标识，且缺少正式`sourceType`、`sourceReference`、`approvalStatus`等治理字段。它们不具备可验证的企业报价或合同来源，因此继续作为样例数据隔离保留，不进入正式`SupplierMaterialPriceRuntime`。

## 服务端审批候选

现有历史核价准备对象可提供供应商、物料、报价金额、币种和来源单号的部分证据，但仍缺少以下正式有效价格字段：

- 最低采购量：采购需求数量不得替代最低采购量；
- 税率；
- 交货周期；
- 生效日期和失效日期。

Runtime逐条输出候选和`missingFields`，但正式列表只接收完整记录。当前正式价格数量为0，候选不进入价格事实、核价有效价输入或采购订单价格来源。

## 后续补全原则

只能由有权维护人员通过既有核价/审批链补齐真实来源与字段，审批完成后形成新版本。禁止根据“业务常识”补造价格，禁止把报价总额、物料数量、Gate参数或页面输入直接提升为企业有效价格。
