# 业务对象来源追踪规范

- 规则编号：`BUSINESS-SOURCE-TRACE-001`
- 生效版本：`V1.14.2.8.4.27.2.21`
- 适用范围：PCE-ERP 业务对象及其子项的跨节点继承
- 状态：长期有效、持续更新

## 1. 权威来源链

业务对象子项必须保留最初业务来源及主数据绑定，流程中间节点只传递身份和决策证据，不得成为基础字段的第二来源。

```text
Source Business Item -> Master Data -> Handoff Identity
-> Target Business Item -> Runtime Adapter -> Page
```

目标对象创建时必须由服务端按来源业务键重新读取权威来源项和主数据；禁止直接把 Gate、页面缓存或临时 Context 中的名称、规格、单位写成最终事实。

## 2. PURCHASE-ORDER-MATERIAL-SOURCE-001

采购订单物料固定来源链为：

```text
PurchaseRequestItem
-> MaterialMaster
-> PurchaseOrderCreationRequest(materialCode + sourceRequestNo)
-> PurchaseOrderItem
```

强制要求：

1. `PurchaseOrderItem.purchaseRequestItemId` 是运行关系字段，必须对应真实 `PurchaseRequestItem.id`；
2. 数据库结构冻结期间，该关系写入现有持久追踪字段并由服务端事实层解析，禁止前端推算；
3. `materialCode` 必须解析到企业 MaterialMaster，找不到时整批阻断并提示“物料主数据未维护”，不得静默创建；
4. 规格采用采购申请已确认规格；采购申请未维护时才读取 MaterialMaster 规格；
5. 单位读取 MaterialMaster 单位，缺失时读取采购申请单位；两者均缺失时阻断；
6. 数量读取 PurchaseRequestItem，价格和供应商决策仍由后续受治理节点提供；
7. 页面只消费服务端输出的来源关系、规格和单位，不得回读 Gate 临时物料。

## 3. 验收门禁

- `PURCHASE-ORDER-MATERIAL-SOURCE-001`：目标明细可追溯到唯一采购申请明细；
- `PURCHASE-ORDER-MATERIAL-MASTER-001`：物料主数据绑定存在且编码一致；
- `PURCHASE-ORDER-MATERIAL-FIELD-001`：specification、unit、quantity、amount、deliveryDate 均为有效业务值。

任一门禁失败时不得创建采购订单，业务写入数必须为 0。
