# 页面真实字段来源追踪规范

- 规则编号：`DOM-FIELD-SOURCE-CHECK-001`
- 生效版本：`V1.14.2.8.4.27.2.18`
- 适用范围：PCE-ERP 所有用户可见业务编号字段
- 状态：长期有效、持续更新

## 1. 真实来源证据

每个业务编号字段必须保存并验证以下四项证据：

1. 业务对象及唯一字段；
2. Runtime 行字段；
3. 页面列字段；
4. 浏览器 DOM 实际文本。

验收必须继续向上追踪到 Provider 与权威数据源：

```text
DOM textContent
-> Vue Component
-> Column Contract
-> Runtime Row
-> Runtime Adapter
-> Provider
-> Server Fact Source
```

静态代码包含目标字段、Runtime 对象存在目标字段或自动测试构造目标值，均不能替代真实浏览器 DOM 证据。

## 2. 强制一致性

业务编号 DOM 的 `textContent` 必须逐字等于当前 Runtime 行的唯一编号字段。页面必须提供只读诊断属性，记录业务对象、Runtime 字段、列字段和行字段值；诊断属性不得计算、转换或回填业务编号。

缺少任一层证据、DOM 与行字段不等、Provider 未读取权威事实或页面从来源对象读取编号时，`DOM-FIELD-SOURCE-CHECK-001` 必须为 FAIL。

## 3. 禁止事项

- 禁止页面拼接、截取、格式化或转换业务编号；
- 禁止 Column Resolver 使用备用编号字段；
- 禁止用 Gate、Handoff、SourceRelations、缓存或演示对象编号替代当前业务对象编号；
- 禁止只验证 `objectNo` 字段存在而不检查浏览器实际文本；
- 禁止为修复显示问题新增第二编号生成器或转换层。

来源编号只能在独立来源关系区域展示，不得进入当前业务编号列。

## 4. PurchaseOrder 专项冻结

```text
Business Object: PurchaseOrder
Unique Field: PurchaseOrder.objectNo
Runtime Field: PurchaseOrderRuntimeModel.objectNo
Schema Column: objectNo
DOM Field: row.objectNo
Server Source: /api/procurement/scm-page-facts/purchase-order/
```

采购订单编号 DOM 必须等于 `row.objectNo`，且不得包含 `PO-SRDB`、`PAP-PI`、`QC-`、`Gate` 或 `SRDB`。Gate 编号只允许出现在来源关系区域。

## 5. 验收记录

验收记录至少保存：版本、URL、DOM 值、组件、列键、行字段、Provider、数据源、截图路径、详情/打印/导出一致性、禁止资产哈希和 `Business Write Count`。
