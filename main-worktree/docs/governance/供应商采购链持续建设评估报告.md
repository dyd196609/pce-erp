## 3. 扫描结论

### 3.1 未接入Runtime的数据

本次四个验收入口及七节点主链未发现需要由页面正式承担的未接入数据。供应商、物料、关系、价格、分析和核价均有既有Runtime/Provider；采购订单由既有服务和事实解析器承接。

### 3.2 重复数据源

目标链路未发现新增重复正式数据源。历史 Platform Meta Runtime 仍是待审计遗留候选，但当前目标页面不以其作为正式所有者。`SupplierPriceFactRuntime`暂位于既有`master_data_statistics_runtime.py`，属于命名/内聚性技术债，不授权本版本搬迁或复制。

### 3.3 页面硬编码

基础资料和价格事实列表的列、筛选、动作已由 Metadata/Schema 和公共 Runtime 驱动。页面仍保留领域说明、区域标题和人工核价表单等业务语义，这是页面职责，不属于通用列表框架硬编码。全仓历史页面仍存在全局Web Acceptance登记缺口，应按独立版本逐页接入，禁止本版本大范围重构。

### 3.4 可智能化增强位置

1. 把采购订单价格来源从兼容文本标记逐步升级为结构化只读追踪；涉及数据库时另立版本。
2. 在既有 SupplierPriceFact/Provider 上增强有效期、税口径与同币种样本完整性，不新建价格Runtime。
3. 将价格异常、交期、质量和绩效证据汇集到推荐/核价只读上下文；最终决策保持人工。
4. 为新增采购链页面强制执行六项增量接入检查和专项Acceptance Profile。
