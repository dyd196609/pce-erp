# 采购订单供应商事实治理验收报告

- Version：`V1.14.2.8.4.27.2.24`
- 数据库结构修改：NO
- Gate模型修改：NO
- MaterialMaster修改：NO
- 价格、金额和交期前端补齐：禁止

## 2. 权威来源链

```text
SupplierMaster
-> SupplierQuotation.SupplierQuoteItem (MaterialSupplierRelation fact)
-> SupplierQuoteItem.unitPrice
-> PurchaseRequest.requiredDate (when quote delivery is absent)
-> PurchaseOrderItem
```

Gate只传递供应商、物料和上游身份。`PurchaseOrderCreationService` 在事务内重新读取 SupplierMaster、PurchaseRequestItem、MaterialMaster 和 SupplierQuotation。前端 `unitPrice` 与 `expectedDate` 不再是创建依据。

## 3. 计算与阻断

- `PurchaseOrderItem.amount = quantity × unitPrice`，由服务端Decimal计算。
- `PurchaseOrder.totalAmount = SUM(item.amount)`。
- 报价单价缺失时抛出 `PURCHASE_PRICE_SOURCE_REQUIRED`，整笔事务回滚。
- 交期优先报价交期，其次供应商物料交期，最后采购申请需求日期。

## 4. 页面投影

采购订单详情从服务端展示：供应商、物料、规格、单位、数量、采购执行单价、金额、交期、价格来源和交期来源。联系电话仅在服务端投影时脱敏，不伪造缺失资料。
