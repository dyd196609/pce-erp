## 4. Supplier Runtime Trace

```text
SupplierRecommendation / PurchaseOrderGate identity
-> PurchaseOrderCreationRequest
-> SupplierBusinessMapping
-> SupplierMaster (procurement.Supplier)
-> PurchaseOrder.supplier
-> SupplierMasterRuntimeAdapter
-> /master-data/suppliers
```

推荐与Gate当前没有独立服务端持久表，其最终供应商身份在采购订单创建时由SupplierMaster重新校验；本版本未读取前端Gate临时供应商作为主数据。
