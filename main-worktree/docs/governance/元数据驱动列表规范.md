# 元数据驱动列表规范

- 规则编号：`METADATA-DRIVEN-LIST-001`
- 生效版本：`V1.14.2.8.4.27.2.35`
- 上位规范：`PCE-ERP智能化开发总纲.md`、`页面字段来源唯一规范.md`、`统一列表规范.md`
- 适用范围：企业基础资料列表及其列、筛选、下拉、操作和统计投影

## 1. 唯一元数据来源

基础资料列表必须复用现有 `masterDataRegistry` 或领域 Runtime 已登记的列表 Metadata。列名称、列数量、筛选字段、筛选类型、选项来源、页面分类和动作策略必须由同一 Metadata 定义投影，页面不得维护第二套字段或按钮数组。

禁止新建平行 Metadata、Registry、Schema、Filter Runtime 或 Dropdown Runtime。通用差距必须在现有所有者文件内兼容扩展。

## 2. 筛选字段契约

- 编码与编号使用 `remote-select`，通过受治理 Dropdown Provider 查询；
- 供应商引用使用 SupplierMaster Runtime；
- 物料引用使用 MaterialMaster Runtime；
- 状态使用 `select`，显示受治理业务标签；
- 日期使用 `daterange`；
- 数量、金额、比率和周期使用 `numberRange`；
- 文本字段使用 `text`。

每个选择型字段必须声明 `optionsSource` 与 `optionsProvider`。Dropdown Provider只返回选项，不得改写业务行或成为主数据第二来源。

## 3. 查询、统计与分页闭环

统一链路为：

```text
Filter Runtime -> Provider Query Projection -> Result Count -> Pagination
```

快速查询、高级筛选和排序必须作用于同一结果集合；“当前结果”、页面统计、分页总数、页数和导出当前结果必须读取该集合。服务端原始总数可以单独标记为“服务端总数”，不得冒充当前筛选数量。

## 4. 操作策略

Metadata必须声明页面分类与动作策略：

- `fact`：只允许查看；
- `master`：允许查看、编辑；
- `config`：允许查看、编辑、停用/启用。

事实页面禁止保存、删除、停用和自动业务决定。列表公共组件只能按 Metadata 动作策略渲染按钮，页面不得额外补造删除或状态动作。

## 5. 验收

- `FILTER-DROPDOWN-COMPLETE-001`：筛选类型与受治理选项来源完整；
- `FILTER-COUNT-SYNC-001`：当前结果、页面统计与分页读取同一结果集合；
- `MASTER-DATA-ACTION-001`：操作列符合页面分类；
- `FACT-VS-MASTER-PAGE-001`：事实与维护页面边界明确且不可互相越权。
