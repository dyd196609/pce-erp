# 页面字段来源唯一规范

- 规则编号：`PAGE-FIELD-SOURCE-UNIQUE-001`
- 生效版本：`V1.14.2.8.4.27.2.17`
- 适用范围：PCE-ERP 全部业务列表、详情、打印与导出字段
- 状态：长期有效、持续更新

## 1. 唯一来源链

每个用户可见业务字段必须拥有且只能拥有一条可追踪来源链：

```text
Business Field -> Runtime Field -> Schema Field -> DOM Field
```

Provider 只能传递服务端事实；RuntimeAdapter 只能把相同业务字段归一到 RuntimeModel；Schema 是列字段名、顺序与业务含义的唯一页面契约；DOM 必须按 Schema 声明的同名字段读取 RuntimeModel。

## 2. 禁止事项

- 禁止页面维护与 Schema 并行的第二套业务列定义。
- 禁止 Page Formatter 改写、拼接、推导或替换业务字段值。
- 禁止 Column Resolver 读取备用字段、兼容别名、来源对象或上一页缓存。
- 禁止用 `displayNo`、`sourceNo`、`sourceObjectNo`、Gate 编号或兼容别名填充业务编号。
- 字段缺失时必须显示空值/不可用并形成诊断，不得静默回退。

格式化器仅允许执行不改变业务事实的视觉格式化，例如日期布局、金额小数位和服务端状态标签展示；业务编号不允许任何格式化或回退。

## 3. 采购订单编号专项

采购订单编号固定映射为：

```text
PurchaseOrder.objectNo
-> PurchaseOrderRuntimeModel.objectNo
-> PurchaseOrderSchema.ui.list.columns[key=objectNo]
-> row.objectNo
-> DOM textContent
```

列表、详情、打印和导出禁止使用 `purchaseOrderNo`、`poNo`、`sourceNo`、`sourceObjectNo`、`gateNo` 或 `displayNo` 作为采购订单编号来源。

## 4. NUMBER-FIELD-LEGACY-BLOCK-003

采购订单编号 DOM 的文本不得包含：

- `PAP-PI`
- `QC-`
- `Gate`（大小写不敏感）
- `SRDB`

任一命中即为 FAIL。该检查必须同时覆盖列表、详情、打印和导出投影；静态代码通过不能替代真实浏览器 DOM 证据。

## 5. 验收边界

验收必须输出 Server、Provider、Runtime、Schema Column、Renderer 与 DOM 六层字段名，并证明字段名均为 `objectNo`。本规范不授权修改编号生成、业务状态、Gate、数据库、生命周期、导入模板或生产业务数据，字段绑定整改必须保持 `Business Write Count = 0`。
