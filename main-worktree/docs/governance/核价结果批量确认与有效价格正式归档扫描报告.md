## 执行前扫描

`PurchasePriceReviewAssistant` 已具备当前报价、历史价格、供应商比较、规则提示和人工确认；人工结果支持接受、拒绝、重新议价三种语义。上一版本仅支持接受报价后单条直接形成会话价格，缺少独立的 `PriceApprovalResult` 服务端事实、人工多选入口和逐条失败隔离。

当前运行数据库仅有 1 条 `SupplierQuotation`，报价单 `SQ-202608050001` 仅有 1 个报价行。因此代码能力可完成批量处理，但真实浏览器无法在不新增数据库测试数据的前提下满足“选择 2 条不同已确认结果”的验收前置条件。

## 复用方案

| 能力 | 正式所有者 | 本版本处理 |
| --- | --- | --- |
| 当前报价 | `SupplierQuotation` | 归档时由服务端重新读取供应商、物料、单价与币种 |
| 人工核价 | `PurchasePriceReviewAssistant` | 原位增加服务端会话 `PriceApprovalResult` |
| 当前有效价格 | `SupplierMaterialPriceRuntime` | 原位增加批量归档，不新增价格模型或第二套审批流 |
| 历史事实 | `SupplierPriceFactRuntime` | 保持只读并排除 `SESSION_CONFIRMED` |
| 页面接入 | 既有 API / Provider / Runtime | 原位扩展批量入口和当前有效价格数量 |
