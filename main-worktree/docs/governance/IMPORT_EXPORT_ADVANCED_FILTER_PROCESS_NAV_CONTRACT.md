# IMPORT / EXPORT / ADVANCED FILTER / PROCESS NAV CONTRACT

## Import template and import

Use only `LatestBaseDataImportToolbarExtension` inside the latest authority composition. Pages must declare applicability. Enabling import requires the complete governed chain and a formal server endpoint. Template columns must come from the same metadata/schema that drives the page. Validation failures must be downloadable or reviewable before confirmation. No automatic or production write is authorized by this contract.

## Export

Export means the current filtered/sorted result under the active formal facts and visible business schema. It must not silently export unrelated rows, technical-only fields or stale browser data.

## Advanced filter

Filters are driven by the registered schema and correct control types. Toggle state, clear behavior, options, applied values and result count must remain consistent.

## Process navigation

Navigation comes from `PceListPageShell` and canonical registries. It shows prior/current/next business context without creating objects, advancing state or performing a business write.

## Data authority

All four capabilities consume the same canonical DB→API→UI identity. Browser storage may hold UI convenience state only; it cannot become formal facts or formal import evidence.
