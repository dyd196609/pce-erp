# SupplierPriceIntelligenceCapabilityInventory

- 版本：`V1.14.2.8.4.27.2.37`
- 结论：复用既有智能化开发体系，不新建 Metadata、Runtime、Registry、Schema 或分析框架。

| 能力名称 | 文件位置 | 当前用途 | 可复用范围 | 是否需要扩展 |
| --- | --- | --- | --- | --- |
| SupplierPriceFact Runtime | `backend/masterdata/master_data_statistics_runtime.py` | 统一报价、供应商物料基础价、采购订单历史价事实 | 价格质量、历史、趋势、比较、异常分析的唯一服务端事实 | 是，在原 Runtime 内增加只读分析输出 |
| Price Fact API | `backend/masterdata/views.py` | 输出价格事实、来源、严格事实与验收事实 | 页面、复制诊断、`strictFacts`、验收共用同一响应 | 是，扩展同一响应，不新增接口 |
| Supplier Price Fact Provider | `frontend/src/meta/providers/supplierPriceFactRuntimeProvider.js` | 获取并缓存价格事实 Runtime | 价格事实页与价格分析页共用 | 否 |
| Supplier Price Fact Frontend Runtime | `frontend/src/meta/runtime/supplierPriceFactRuntime.js` | 校验事实来源、唯一性和无自动决策边界 | 规范化历史、比较、异常只读结果 | 是，在原 Runtime 内增加校验和展示归一化 |
| Metadata Registry | `frontend/src/meta/master-data/masterDataRegistry.js` | 企业基础资料列、筛选和操作策略注册 | 历史价格与供应商比较列表配置 | 是，仅登记新页面的列表元数据 |
| Filter Runtime | `frontend/src/meta/runtime/listFilterRuntime.js` | 元数据驱动筛选、计数与分页链 | 历史价和比较列表筛选 | 否 |
| Dropdown Runtime | `frontend/src/meta/runtime/remoteSelectOptionsProvider.js` | SupplierMaster、MaterialMaster 远程下拉 | 供应商和物料筛选 | 否 |
| Enterprise List | `frontend/src/meta/components/FoundationMetadataList.vue` | 复用企业列表、高级筛选、状态与操作规范 | 两个只读分析列表 | 否 |
| 既有核价参考上下文 | `frontend/src/meta/process/scm/priceApproval/priceReferenceContext.js` | 局部核价流程的历史最低、最近、变化参考 | 仅用于能力佐证；不得作为本页事实源 | 否，不直接接入 |
| 既有价格变化证据 | `frontend/src/meta/process/scm/priceApproval/priceChangeEvidence.js` | 局部价格变化证据整理 | 规则设计参考 | 否，不直接接入 |
| 通用成本智能引擎 | `frontend/src/meta/intelligence/costIntelligenceEngine.js` | 自动选择低成本路径 | 不适用于本版本只读边界 | 否，明确禁止复用其自动决策行为 |
| 通用风险引擎 | `frontend/src/meta/intelligence/riskEngine.js` | 通用业务风险提示 | 后续可扩展价格风险信号 | 暂缓，当前使用 SupplierPriceFactRuntime 的确定性规则 |

## 复用结论

- 列、筛选、下拉、列表、页面壳、可观测性均复用已有实现。
- 分析逻辑只扩展既有 `SupplierPriceFactRuntime`；页面不重算最低价、最近价、平均价、变化率或异常。
- 未发现可安全直接复用且不产生自动决策的完整价格分析框架，因此不创建第二套体系。
- 自动选择最低价或自动推荐供应商与本版本边界冲突，保持关闭。
